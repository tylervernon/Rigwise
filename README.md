# Rigwise

Rigwise is an interactive PC recommendation platform that helps users plan a gaming PC based on their budget, games, performance goals, and upgrade priorities.

## Features

- Guided PC-building recommendation process
- Budget-based component recommendations
- Game and FPS-based performance planning
- CPU and GPU compatibility logic
- Storage selection based on user needs
- Upgrade-priority recommendations
- Support for different hardware platforms and memory generations

## Tech Stack

- React
- TypeScript
- JavaScript
- HTML
- CSS
- Replit

## Status

**In active development.**

Rigwise is an ongoing project, with additional recommendation logic, hardware data, and features still being developed.

## Purpose

I built Rigwise to combine my interests in computer hardware and software development while creating a practical tool for helping users make PC-building decisions.
